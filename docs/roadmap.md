# Roadmap

- [x] **Etapa 1 — Fundação**: repositório, frontend, backend, ambiente, documentação inicial
- [x] **Etapa 2 — Biblioteca documental**: upload, Supabase Storage, listagem, extração de texto
- [ ] **Etapa 3 — Processamento e embeddings**: chunking, metadados, provedores de embedding, vetores
- [ ] **Etapa 4 — Busca semântica**: pgvector, recuperação, testes de relevância
- [ ] **Etapa 5 — RAG funcional**: provedor de LLM, pipeline de geração, referências
- [ ] **Etapa 6 — Interface de conversação**: chat, histórico, fontes
- [ ] **Etapa 7 — Laboratórios**: inspeção de chunks, scores, prompts, métricas
- [ ] **Etapa 8 — Múltiplos provedores**: adaptadores, seleção e comparação de modelos
- [ ] **Etapa 9 — Avaliação e evolução**: métricas de qualidade, busca híbrida, reranking
